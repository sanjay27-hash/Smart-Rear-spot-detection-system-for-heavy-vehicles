# Smart-Rear-spot-detection-system-for-heavy-vehicles

Smart Rear Distance Warning System for Heavy Vehicles

Project Overview

This project is designed to improve rear-distance awareness for heavy vehicles by detecting vehicles approaching from behind.

The system measures the distance using an ultrasonic sensor and provides visual and audible warnings based on the detected distance.

Components Used

- Arduino Uno R3
- HC-SR04 Ultrasonic Sensor
- 16×2 LCD Display
- Green LED
- Yellow LED
- Red LED
- Buzzer
- Resistors
- Breadboard and jumper wires

Working Principle

1. The ultrasonic sensor measures the distance to an object behind the vehicle.
2. The Arduino processes the measured distance.
3. The LCD displays the distance in centimeters.
4. LEDs indicate different warning levels.
5. The buzzer alerts the driver when an object gets too close.

Warning Levels

- Green: Safe distance
- Yellow: Caution
- Red: Warning or danger
- Buzzer: Audible distance warning
